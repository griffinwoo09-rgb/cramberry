# Cramberry

A free study app. Import vocab lists (paste text or open a CSV), then learn them with flashcards, Learn rounds, practice tests, and five games: Match, Memory Flip, Bubble Pop, Lightning Round, and Unscramble.

Everything runs in one HTML file. Sets are saved in your browser's local storage; use Export to move them to another device.

**Play it:** https://griffinwoo09-rgb.github.io/cramberry/
