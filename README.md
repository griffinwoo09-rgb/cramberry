# Cramberry

A free study app. Paste a vocab list or open a CSV, then study it with flashcards, Learn rounds, practice tests, and five games: Match, Memory Flip, Bubble Pop, Lightning Round, and Unscramble.

Everything runs in one HTML file. Sets are saved in your browser's local storage; use Export to move them to another device.

**Play it:** https://griffinwoo09-rgb.github.io/cramberry/
